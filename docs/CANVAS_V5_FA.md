# Canvas v5 — بارگذاری هنگام تعامل

نسخه v5 به‌جای دانلود همه فریم‌ها در لحظه ورود به صفحه، فقط پس از Hover، لمس یا Focus روی لباس دارای انیمیشن تأییدشده بارگیری را آغاز می‌کند. تا کامل‌شدن دانلود، رگال CSS 3D اصلی بدون تغییر نمایش داده می‌شود. بعد از خروج از اولین تعامل، Canvas برای چرخش رفت‌وبرگشت بعدی فعال می‌شود.

- ورودی معتبر: `verified:true` و فریم‌هایی در مسیر `/assets/turns/<id>/001.webp`.
- `public/assets/turn-manifest.json` در حال حاضر **خالی** است؛ هیچ عکس یا لباس مصنوعی به عنوان محصول واقعی نمایش داده نمی‌شود.
- پشتیبانی خطای فریم، حالت کاهش حرکت و پاک‌سازی هنگام تعویض دسته‌بندی در نظر گرفته شده است.
- تست محلی در Chromium در اندازه‌های 320، 390، 768 و 1440 انجام شد. تست‌ها با فریم شماتیک هستند، نه عکس واقعی محصولات.
- فایل‌های تست و راهنمای کامل در ZIP نسخه ۵ ارائه شده‌اند.
- پرداخت واقعی راه‌اندازی نشده و تصاویر اصلی هنوز از دامنه 369clothing.ir بارگیری می‌شوند.

برای غیرفعال‌سازی این قابلیت، فهرست manifest را خالی نگه دارید یا تگ‌های دو اسکریپ Canvas را از HTML بردارید.
