# گزارش فنی نسخه v6 — 369 Clothing
آخرین بررسی کاتالوگ: ۲۰۲۶-۱۰-۱۴.

## تغییرات
- صفحه فروشگاه در `index.html` و `public/index.html` یکسان است؛ موتور اصلی Mkurugenzi و Canvas v5 حفظ شده‌اند.
- هر کارت محصول دارای لینک استعلام قیمت، سایز و موجودی در فروشگاه اصلی است.
- قیمت‌های نمایش داده شده Snapshot هستند؛ موجودی هیچ‌یک از ۱۷ مورد به‌صورت زنده بررسی نشده است.
- ابزار بررسی دستی رسانه در مسیر `/media-check.html` اجرا می‌شود؛ خروجی آن به اینترنت و مرورگر اجراکننده وابسته است. این صفحه فقط از عکس‌های عمومی درخواست بارگیری می‌کند و هیچ اطلاعات شخصی ذخیره نمی‌کند.
- فهرست اولیه رسانه‌ها در `public/media-catalog.json` برای مرور کیفیت قرار دارد.

## تست انجام‌شده در محیط توسعه
- تست سینتکس JavaScript توسط Node.
- Chromium در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸، ۱۴۴۰: بدون خطای runtime JS یا اسکرول افقی.
- ۱۷ کارت، ۱۷ لینک استعلام؛ فیلتر شلوار ۳ مورد، بازگشت به ۱۷ مورد.
- شبیه‌سازیِ موفقیت یک عکس و شکست ۱۶ عکس برای ابزار بررسی رسانه.
- تست‌ها به‌دلیل محدودیت شبکه، واقعی‌بودن یا دسترسی زنده عکس‌ها را تأیید نکردند.

## محدودیت‌های ناتمام برای کیفیت تجاری ۱۰/۱۰
- فایل معتبر نمای کنار و توالی WebP واقعی برای کالاها موجود نیست؛ فایل manifest همچنان خالی است و CSS 3D فعال می‌ماند.
- موجودی و قیمت فروشگاه اصلی به‌صورت لحظه‌ای همگام نمی‌شوند.
- پرداخت و ثبت سفارش واقعی در این پیش‌نمایش غیرفعال است.
- کیفیت تصاویر بر بستر شبکه واقعی/آیفون باید با ابزار رسانه و تست چشمی تأیید شود.
