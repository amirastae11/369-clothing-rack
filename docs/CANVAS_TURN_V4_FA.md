# 369 Clothing — موتور چرخش تصویری v4 (حالت اختیاری)

این ارتقا بر پایه راهنمای عمومی Notion «The Clothing Rack Landing Page — Full Guide + Prompts» طراحی شده و سورس Mkurugenzi اصلی را کنار نمی‌گذارد.

## چه چیزهایی آماده است؟
- `assets/clothing-turn-player.js`: پخش فریم‌های WebP روی Canvas با حرکت ۱.۱ ثانیه‌ای و حالت رفت و برگشت.
- `assets/turn-adapter.js`: اتصال خودکار به رگال 369، فقط برای محصولات دارای مجموعه‌فریم تأییدشده.
- `assets/turn-manifest.json`: فهرست محصولاتی که مجاز به جایگزینی انیمیشن CSS هستند. تا وقتی خالی است ظاهر فروشگاه تغییر نمی‌کند.
- `tests/validate_frames.py`: بررسی تعداد، نام‌گذاری، ابعاد و شفافیت گوشه‌های فریم‌ها.

## دستورالعمل آماده‌سازی اولین محصول
1. تصویری واقعی از روبه‌روی محصول 369 و در صورت امکان نمای کنار واقعی بگیرید یا از صاحب فروشگاه تهیه کنید.
2. اگر نمای کنار یا فریم AI ساخته شد، برچسب «نمای تولیدشده برای نمایش» را در فرایند بررسی و نمایش حفظ کنید. جزئیات طرح، لوگو، رنگ و متن لباس باید با کالای واقعی سازگار باشند. تصویر AI را عکس واقعی کالا معرفی نکنید.
3. یک ویدیوی چرخش واقعی یا تولیدشده با مرجع دقیق، با دوربین ثابت و چرخش کنار به روبه‌رو تهیه کنید.
4. فریم‌های شفاف 480×480 را با نام‌های مرتب `001.webp` تا `0NN.webp` در `public/assets/turns/<product-id>/` قرار دهید. سفید خالص بدون شفافیت کافی نیست.
5. اعتبارسنجی: `python tests/validate_frames.py public/assets/turns/<product-id>`
6. فهرست را در `public/assets/turn-manifest.json` تکمیل کنید. فقط پس از تست موبایل، دسکتاپ و تأیید بصری، `verified:true` کنید.
7. انیمیشن هر لباس تنها پس از بارگیری **تمام فریم‌ها** فعال می‌شود؛ در خطا، لباس به همان موتور 3D قبلی برمی‌گردد.

مثال بدون فعال‌سازی خودکار:
```json
{
  "version": 1,
  "garments": [
    {
      "name": "تیشرت آستین بلند سبز چهارخونه",
      "verified": false,
      "frames": ["/assets/turns/369-01/001.webp", "/assets/turns/369-01/002.webp"]
    }
  ]
}
```
`verified:true` فقط در صورت کامل‌بودن فریم‌ها و آزمون دستی مجاز است.

## یادداشت‌های امنیتی و عملکرد
- فریم‌ها باید روی همان دامنه و مسیر `/assets/turns/` باشند. بارگذاری از دامنه ناشناس پذیرفته نمی‌شود.
- حداکثر ۱۲۰ فریم برای هر لباس؛ ۱۲ تا ۴۰ فریم برای موبایل معمولاً مناسب‌تر است.
- شفافیت واقعی (alpha) لازم است؛ نمای سفید با `mix-blend-mode` به‌خصوص لباس روشن را خراب می‌کند.
- در حالت کاهش حرکت (`prefers-reduced-motion`) انیمیشن بدون حرکت میانی، به حالت نهایی جابه‌جا می‌شود.
- **پرداخت واقعی همچنان غیرفعال است.** لینک خرید باید به فروشگاه اصلی برود.
- آزمایش‌های این نسخه با لباس شماتیک انجام شدند؛ فایل آزمایشی در انتشار آنلاین قرار ندارد.

## استقرار و بازگشت
هر دو `index.html` و `public/index.html` فایل ورودی سایت هستند. Cloudflare Workers از `public/` سرو می‌کند. با خالی‌بودن فهرست فریم‌ها، سایت همان نسخه قبلی را نمایش می‌دهد. برای خاموش‌کردن Canvas کافی است اسکریپت‌های اختیاری را از HTML حذف یا فهرست را خالی کنید؛ موتور اصلی دست‌نخورده است.
